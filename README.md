# Steven Y.M. Siahaan — Portfolio

A responsive static portfolio website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and semantic structure
- `styles.css` — responsive visual design, dark/light themes, animations
- `script.js` — theme toggle, mobile navigation, scroll reveal effects

## Run locally
Open `index.html` directly in your browser, or use VS Code Live Server.

## Deploy to Netlify
1. Log in to Netlify.
2. Choose **Add new site → Deploy manually**.
3. Drag the entire `steven-portfolio` folder into Netlify Drop.
4. Netlify will generate a public URL.

No build command is required.
